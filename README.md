# 🛍️ Customer Segmentation Analysis Using K-Means Clustering

## 📌 Project Overview

This project focuses on customer segmentation for an e-commerce business using **RFM (Recency, Frequency, Monetary) analysis and K-Means clustering**.

The objective is to identify groups of customers with similar purchasing behavior and develop targeted marketing strategies to improve customer retention, engagement, and revenue.

The project uses Python for data preprocessing, feature engineering, clustering, visualization, and customer profiling.

## 🎯 Objectives

- Load and inspect the e-commerce transaction dataset.
- Handle missing values, duplicate records, cancelled invoices, and invalid transactions.
- Calculate customer-level purchasing metrics.
- Perform RFM analysis to understand customer behavior.
- Calculate average purchase value, purchase frequency, and historical customer spending.
- Select relevant behavioral features for clustering.
- Apply logarithmic transformation and standardization using `StandardScaler`.
- Use the Elbow Method to estimate a suitable number of clusters.
- Evaluate candidate cluster counts using silhouette scores.
- Implement K-Means clustering using Scikit-learn.
- Visualize customer segments using scatter plots.
- Profile each cluster and analyze its contribution to customers and revenue.
- Develop marketing recommendations for the identified segments.

## 📂 Dataset

This project uses the **Online Retail dataset** from the UCI Machine Learning Repository.

**Dataset link:** https://archive.ics.uci.edu/dataset/352/online+retail

The original dataset contains transaction records from a UK-based online retailer covering December 2010 to December 2011.

### Dataset attributes

| Column | Description |
|---|---|
| `InvoiceNo` | Invoice or transaction identifier |

| `Quantity` | Quantity purchased |
| `InvoiceDate` | Transaction date and time |
| `UnitPrice` | Price per unit in British pounds |
| `CustomerID` | Customer identifier |

The data includes multiple transactions for individual customers, making it suitable for RFM-based customer segmentation.

**Dataset citation:** Chen, D. (2015). *Online Retail*. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33

## 🔍 Methodology

### 1. Data Loading and Inspection

The dataset is loaded using Pandas and inspected to understand its structure, data types, missing values, duplicate records, and numerical distributions.

### 2. Data Cleaning and Preprocessing

The preprocessing stage includes:

- Removing duplicate records.
- Handling missing customer identifiers.
- Converting transaction dates and numerical columns to appropriate data types.
- Excluding cancelled invoices from purchase analysis.
- Removing transactions with non-positive quantities or unit prices.
- Calculating transaction-line revenue.

These steps help ensure that customer metrics are based on valid purchase records.

### 3. RFM Feature Engineering

Customer-level features are calculated from transaction data.

**Recency:** Number of days since the customer's most recent purchase.

**Frequency:** Number of distinct invoices associated with the customer.

**Monetary:** Total historical revenue generated by the customer.

The analysis also calculates average purchase value and historical customer spending to support customer profiling.

Historical spending is used as a measure of observed customer value, not as a prediction of future customer lifetime value.

### 4. Exploratory Analysis

Histograms are used to examine the distributions of Recency, Frequency, and Monetary values. This helps identify skewness and differences in purchasing behavior.

### 5. Feature Transformation and Standardization

The selected RFM features are transformed using `log1p` to reduce right-skew and standardized using `StandardScaler`.

Standardization prevents features with larger numerical scales from disproportionately influencing the distance calculations used by K-Means.

### 6. Optimal Cluster Selection

The Elbow Method is used to compare inertia values across different numbers of clusters.

Silhouette scores provide an additional measure of cluster separation. The final cluster count is selected by considering both evaluation metrics and the interpretability of the customer segments.

### 7. K-Means Clustering

The K-Means algorithm groups customers according to similarities in their standardized RFM features.

Each customer receives a cluster identifier that can be used for subsequent customer profiling and marketing analysis.

### 8. Cluster Visualization

Scatter plots are created to visualize the customer segments using two feature combinations:

- Recency versus Monetary.
- Frequency versus Monetary.

The charts help illustrate how the clusters differ in purchasing recency, frequency, and historical spending.

### 9. Customer Profiling

For each cluster, the analysis calculates:

- Number of customers.
- Mean and median Recency.
- Mean and median Frequency.
- Mean and median Monetary value.
- Average purchase value.
- Percentage of total customers.
- Percentage of total historical revenue.

These metrics help translate numerical cluster assignments into understandable customer segments.

### 10. Cluster Size Analysis

A bar chart displays the number of customers assigned to each cluster. This helps compare segment sizes and determine whether a segment represents a broad audience or a smaller customer group.
